# Cycle

Period tracker that runs as an installable web app. All data stays on the phone (IndexedDB).

## Deploy on GitHub Pages
1. Create a new GitHub repository (e.g. `cycle`).
2. Upload every file in this folder to the repository root.
3. Settings > Pages > Source: "Deploy from a branch", Branch: `main`, folder `/ (root)`. Save.
4. After a minute the app is live at `https://<username>.github.io/cycle/`.

## Install on iPhone
1. Open that URL in **Safari**.
2. Share button > **Add to Home Screen**.
3. Always open the app from the Home Screen icon. Its data lives there, separate from Safari.

## Moving your data in
Open the old version, tap **Export backup**, then in the installed app tap **Import backup** and pick the file.

## Important
Deleting the Home Screen icon deletes the app's data. Export a backup regularly.
